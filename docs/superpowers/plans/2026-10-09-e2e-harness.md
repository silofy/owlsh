# Browser E2E Harness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `npm run e2e` runs real-Chromium tests against the production bundle, with a fake desktop layer and scripted model, covering every AI-hint flow and a smoke pass over the main views; CI runs it.

**Architecture:** `@playwright/test` serves `vite preview` of the built app. Before app scripts run, a fixture defines `window.__TAURI_INTERNALS__.invoke` that forwards every call to a Node-side router (`page.exposeFunction`), so tests set replies and read calls without touching app code. Model replies come through the faked `cloud_generate` command (the app's real `CloudProvider` runs). One app change: a test-only timeout override.

**Tech Stack:** Playwright 1.61.1 (`@playwright/test` pinned to match the existing `playwright`), Vite 6 preview, TypeScript, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-09-e2e-harness-design.md`

## Global Constraints

- `@playwright/test` version exactly `1.61.1` (matches existing `playwright`).
- Tests run against `vite preview` of `npm run build`, Chromium only.
- Unknown native commands are recorded as "unmocked" and fail the test at teardown unless the test allows them.
- A page `console.error` or uncaught page error fails the test unless explicitly allowed.
- Waits are on observable UI or recorded calls (`expect.poll`, locator assertions) — never fixed sleeps.
- Model replies use synthetic placeholder content only.
- Production defaults unchanged: hint timeout 8000 ms, golden budget 30000 ms; override only via `window.__OWLSH_TEST__`.
- `e2e/` is excluded from vitest; vitest files are excluded from Playwright.
- CI retries 1, local retries 0; upload `playwright-report/` on failure.
- Commits carry no `Co-Authored-By` trailer.

## Review Focus

1. **The app's first native call happens before the test registers a handler** → the default handler set must make startup succeed with zero test setup (smoke in desktop mode proves it; Task 2 self-test).
2. **A test leaves a handler mid-flight when it ends** (slow model reply) → teardown must not hang or throw; the pending exposed-function promise is abandoned cleanly (Task 2 self-test: slow handler + test end).
3. **Port 4173 already in use locally** → `reuseExistingServer` locally, fresh server in CI (Task 2 config).
4. **Polling makes recorded-call counts grow** (`latest_session` every 2 s) → hint assertions count only `record_hint`/`record_golden`, never poll commands (Tasks 4–5 assert on those only).
5. **localStorage leaking between tests** → each test gets a fresh browser context (Playwright default); the opt-in tests assert the pref starts unset (Task 4).

```ts
/** Test-only knobs for the browser e2e suite. Production never defines `__OWLSH_TEST__`. */
type Key = "hintTimeoutMs" | "goldenBudgetMs";

export function testOverride(key: Key): number | undefined {
  const v = (globalThis as { __OWLSH_TEST__?: Partial<Record<Key, unknown>> }).__OWLSH_TEST__?.[key];
  return typeof v === "number" && Number.isFinite(v) && v > 0 ? v : undefined;
}
```

- [ ] **Step 3: The desktop fake** (`e2e/fixtures/tauri.ts`). Shape:

```ts
import type { Page } from "@playwright/test";

type Handler = unknown | ((args: Record<string, unknown>) => unknown | Promise<unknown>);

/** Defaults that let the app start with zero test setup (Review Focus 1). Read src/lib/llm/runtime.ts
 *  for ollama_status's real return shape and default it to "not running". */
const DEFAULTS: Record<string, Handler> = {
  list_sessions: [],
  list_ssh_logs: [],
  latest_session: null,
  has_api_key: false,
  has_htb_token: false,
  record_hint: null,
  record_golden: null,
  // ollama_status: <shape for "unreachable">,
};

export class TauriFake {
  private handlers = new Map<string, Handler>(Object.entries(DEFAULTS));
  private log: { cmd: string; args: Record<string, unknown> }[] = [];
  private unmocked = new Set<string>();
  private allowed = new Set<string>();
  constructor(private page: Page) {}

  async install(opts: { test?: Record<string, number>; storage?: Record<string, string> } = {}) {
    await this.page.exposeFunction("__owlshTauri", async (cmd: string, args: Record<string, unknown>) => {
      this.log.push({ cmd, args: args ?? {} });
      if (!this.handlers.has(cmd)) { this.unmocked.add(cmd); return { err: `unmocked: ${cmd}` }; }
      const h = this.handlers.get(cmd);
      try { return { ok: typeof h === "function" ? await (h as (a: Record<string, unknown>) => unknown)(args ?? {}) : h }; }
      catch (e) { return { err: e instanceof Error ? e.message : String(e) }; }
    });
    await this.page.addInitScript(({ test, storage }) => {
      for (const [k, v] of Object.entries(storage ?? {})) localStorage.setItem(k, v);
      if (test) (window as unknown as { __OWLSH_TEST__: object }).__OWLSH_TEST__ = test;
      let id = 0;
      (window as unknown as { __TAURI_INTERNALS__: object }).__TAURI_INTERNALS__ = {
        invoke: async (cmd: string, args: Record<string, unknown>) => {
          const r = await (window as unknown as { __owlshTauri: (c: string, a: unknown) => Promise<{ ok?: unknown; err?: string }> }).__owlshTauri(cmd, args);
          if (r.err !== undefined) throw r.err;
          return r.ok;
        },
        transformCallback: () => ++id,
        unregisterCallback: () => {},
        convertFileSrc: (p: string) => p,
        metadata: { currentWindow: { label: "main" }, currentWebview: { label: "main", windowLabel: "main" } },
      };
    }, { test: opts.test, storage: opts.storage });
  }

  on(cmd: string, h: Handler) { this.handlers.set(cmd, h); }
  calls(cmd: string) { return this.log.filter((c) => c.cmd === cmd).map((c) => c.args); }
  allowUnmocked(cmd: string) { this.allowed.add(cmd); }
  /** Commands called without a handler and not allowed — checked at teardown. */
  strayUnmocked() { return [...this.unmocked].filter((c) => !this.allowed.has(c)); }
}
```

```ts
import type { TauriFake } from "./tauri";

export type ModelReply =
  | { kind: "json"; body: { hint: string; kind: string } }
  | { kind: "slow"; ms: number; body: { hint: string; kind: string } }
  | { kind: "error" };

export const clean = (hint: string, kind = "process"): ModelReply => ({ kind: "json", body: { hint, kind } });
/** A URL-shaped hint — the guard's artifacts rule must block it. */
export const leaky = (): ModelReply => ({ kind: "json", body: { hint: "Look at http://example.test/admin next.", kind: "process" } });
export const slow = (ms: number, hint = "Re-read your last output."): ModelReply => ({ kind: "slow", ms, body: { hint, kind: "process" } });
export const error = (): ModelReply => ({ kind: "error" });

export class ModelFake {
  constructor(private tauri: TauriFake) {}
  /** Coach mode must already be "anthropic" in storage — pass COACH_CLOUD to tauri.install({ storage }). */
  useCloud(...replies: ModelReply[]) {
    let i = 0;
    this.tauri.on("has_api_key", true);
    this.tauri.on("cloud_generate", async () => {
      const r = replies[Math.min(i++, replies.length - 1)];
      if (r.kind === "error") throw new Error("model error");
      if (r.kind === "slow") await new Promise((res) => setTimeout(res, r.ms));
      return JSON.stringify(r.body);
    });
  }
}

export const COACH_CLOUD = { "owlsh.coachMode": "anthropic" };
```
